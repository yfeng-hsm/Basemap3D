Reproduction of C_balanced. Install numpy, rasterio, scipy, scikit-image, pyproj, Pillow, trimesh, Node.js and gltf-validator. Download the original rasters and terrain cache documented in ../data/input_manifest.json. Adjust local paths in the scripts and provide broadleaf_unit.glb and Cesium.js. Run process_center.py, sample_terrain.mjs, build_tiles.py, then validate_tiles.mjs. Script paths reflect this processing run; raw input rasters and the external terrain cache are not included.
