Get started

Your first map.

Download the repository, then install from its root folder. Python 3.10+ and an internet connection are required.

python -m pip install -e ".[notebook]"
python -m jupyterlab

Display or export.

from basemap3d import Map

m = Map(location=[50.0063, 8.2692], zoom_start=16)
m.save("results/map.html")
m

In Jupyter, finish a cell with m. To open an exported scene locally, serve the folder with a local web server such as Go Live.

Use Google Colab

Open a notebook from Examples, connect a fresh runtime and run the setup cell first. The wrapper manages the Colab display server automatically.
